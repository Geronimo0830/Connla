# Connla v0.1.1 · 桌面版备份与恢复

这一版在桌面版管理员的「设置 → 备份与恢复」中加入整库备份与恢复。创建备份时可选择目标文件夹；恢复时选择包含 `manifest.json` 的备份文件夹，并在系统确认窗口中确认。操作期间本地服务会短暂停止，完成后自动重新启动。

恢复前，程序先为当前数据创建安全备份，并保留原数据目录。若新数据无法启动，会尝试自动回退；如果操作意外中断，下次启动会优先恢复原数据。备份使用清单、SHA-256 和 SQLite 完整性校验；这能发现损坏，不能证明备份来源可信。请只恢复你信任的备份，并将重要备份另存到其他磁盘。

个人数据仍保存在 `%LOCALAPPDATA%\PersonalKnowledgeBase\data`，不在发布压缩包内。完整解压 Windows x64 压缩包，双击 `Connla.exe`；需要 Microsoft Edge WebView2 Runtime。更多说明见 [桌面版使用说明](https://github.com/Geronimo0830/Connla/blob/v0.1.1/docs/LOCAL_DESKTOP.md)。

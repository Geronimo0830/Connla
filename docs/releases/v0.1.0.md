# Connla v0.1.0 · Windows 桌面版

Connla 现在可以作为独立窗口运行：下载 `Connla-v0.1.0-windows-x64.zip`，完整解压后双击 `Connla.exe`。不需要安装 Go、Node.js 或 Docker，也不需要在浏览器中打开界面。

本版保留文档收件箱、知识卡片、学习主题和知识搜索；暂不提供知识复习入口。README 中的展示图已更新为桌面版实拍，并遮盖了账号信息。

个人数据保存在 `%LOCALAPPDATA%\PersonalKnowledgeBase\data`，不在压缩包内。升级前请先关闭程序并备份。桌面版内部仍使用仅监听 `127.0.0.1:8081` 的本地服务；需要 Windows x64 和 Microsoft Edge WebView2 Runtime。当前没有安装向导、自动更新或内置备份按钮。详见 [桌面版说明](../LOCAL_DESKTOP.md)。
